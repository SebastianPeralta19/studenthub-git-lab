# Guía de Contribución

¡Gracias por tu interés en contribuir a este proyecto!

## Pasos para colaborar
1. Crea una nueva rama para tus cambios.
2. Asegúrate de hacer commits claros y descriptivos.
3. Abre un Pull Request orientando detalladamente tu contribución.
4. Reportar bugs mediante la sección de Issues.
5. Mantener una sola funcionalidad por cada Pull Request.
